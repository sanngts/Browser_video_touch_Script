A simple and lightweight script designed to solve the trouble of not being able to easily drag the progress bar with your finger when watching web videos on a touchscreen computer.

Note: The plugin currently only works in fullscreen mode.

v1.1
- Long press the screen for 0.5 seconds and then drag to the right to activate 2x speed playback.  
- Swipe up or down to adjust video brightness.

v1.1.3
- Fixed several plugin failures.
- Resolved errors that could occur when processing multiple videos.

Download the JS file.  
Import the file into ScriptCat.  
Enable the script and refresh the webpage.
